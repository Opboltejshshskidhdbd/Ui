🛠️ Project Focus

Roblox Dev Master aims to support:

- Luau Code Analysis — Identify potential code defects.
- Validation Results — Present errors, warnings, and informational findings.
- Type Analysis — Display type-related diagnostics where supported.
- Roblox API Checks — Help identify potentially invalid API usage.
- Readable Reports — Make validation results easier to understand.
- Engineering Quality — Encourage secure, maintainable, and reliable Roblox systems.

⚠️ Validation Disclaimer

External validation results depend on the validator's actual capabilities. A successful validation result does not necessarily prove that code compiles in the official Roblox Luau compiler or works correctly at runtime.

🎯 Goal

Build a reliable Roblox development assistant that combines useful diagnostics, readable UI, and rigorous engineering practices.
